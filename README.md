# Power BI – Vězněné osoby v Česku

Projekt vytvořený v rámci Engeto Data Academy.

## Popis projektu
Projekt analyzuje vývoj a strukturu vězněných osob v Česku v letech 2005–2025.

Analýza se zaměřuje na:
- trestné činy
- recidivu
- věkové skupiny
- pohlaví a vývoj v čase
- občanství

Data pro analýzu trestných činů jsou dostupná pouze za období 2005–2022.

## Zdroje dat
- Český statistický úřad (ČSÚ) – Odsouzené osoby podle druhu kriminality
- Český statistický úřad (ČSÚ) – Vězněné osoby
